# UI/UX & Aesthetic Standards
- **Modern Look**: Follow "Glassmorphism" principles (subtle blurs, semi-transparent backgrounds).
- **Animations**: Use smooth transitions for piece movements and UI state changes.
- **Tailwind 4**: Leverage Tailwind 4 features for styling.
- **Responsiveness**: Ensure the chessboard and sidebar are usable on both desktop and mobile layouts.
- **Interactive Feedback**: Provide clear visual cues for valid moves, selected pieces, and game states (Check, Mate, Stalemate).
